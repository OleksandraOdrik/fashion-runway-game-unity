# Fashion Runway Game 🎀

A fashion-themed 3D mini-game created as a university Digital Media project using **Unity** and **Blender**. The project combines character design, interactive 3D environments, animation, interface design and gameplay mechanics.

## About the game

Explore a fashion-inspired environment as a stylised character and collect handbags placed around the runway and surrounding rooms **before the timer runs out**. The aim is to collect all required bags to win. A special golden bag awards bonus points.

## Features

- **Custom 3D character:** Model created in Blender and imported into Unity using FBX.
- **Third-person movement:** Keyboard controls, camera-relative movement and mouse-controlled camera.
- **Character animation:** Idle and walking states controlled by Unity's Animator.
- **Collectibles and scoring:** Handbags to collect, a bonus golden bag, a countdown timer and win/lose conditions.
- **Custom user interface:** Start and instruction screens, in-game score and timer, countdown, and end menu.
- **Audio:** Background music, collection sound effects and a mute control.
- **Visual design:** A coordinated pink-and-purple fashion aesthetic, using original and third-party environment assets.
